# 0002. 分发方式：仅侧载自用

## 背景

产品是个人厨房笔记，用户就是作者本人。是否投入应用商店上架（软著、App 备案、隐私政策、渠道适配、审核）会显著影响开发节奏与功能取舍。

## 选项

| 选项 | 成本 | 约束 |
|---|---|---|
| 仅侧载（APK） | 低 | 自行安装与更新；无商店流量 |
| 国内商店 | 高（软著 + 备案 + 隐私政策 + 渠道包） | 审核对下载/解析类敏感 |
| Google Play | 高（数据安全表单 + targetSdk 硬要求） | 同样禁止绕过平台限制 |

## 决定

**仅侧载自用**：

1. 产出签名 APK，直接安装到自己的手机与平板；不做商店包、不做 ASO。
2. 不接入任何广告、统计、崩溃上报 SDK；如需要日志，只在本地保存。
3. 仍然遵守数据最小化与隐私原则（无账号、无上传、无后台联网）。
4. 更新方式：本地构建 → 覆盖安装；数据库与文件迁移必须保证向后兼容（见 ADR 0004）。

## 后果

- 正面：省掉 1-2 个月的合规流程；可以按个人习惯做取舍；不必为审核改文案或删功能。
- 负面：换设备需要手动装 APK；没有商店的自动更新；如果未来分享给他人，需要重新评估合规。
- 不影响：ADR 0001 的红线（不下载、不去水印）与"仅自己用"无关，仍然有效。

## 触发重审的条件

- 要把应用发给家人/朋友；
- 要上架任何商店；
- 要在应用内加入任何联网或付费能力。
