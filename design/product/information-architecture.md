# 信息架构与导航

> **2026-11-03 说明**：首页「今晚吃什么」、烹饪模式与记录已被 [`ui-change-proposal.md`](ui-change-proposal.md) 取代（改为今天菜单、步骤内计时、备注与历史快照）；本文的站点地图与首页逻辑尚未同步，冲突时以提案为准。

## 1. 断点

| 尺寸 | 宽度 | 导航 | 布局 |
|---|---|---|---|
| Compact | <600dp | 底部 Tab 4 个 + 悬浮收录按钮 | 单栏，列表→详情 |
| Medium | 600-840dp | NavigationRail + 列表 | 列表两列；详情单栏 |
| Expanded | ≥840dp | NavigationRail + 列表 + 详情双栏 | 三栏：导航/列表/详情；烹饪模式左右分屏 |

不锁竖屏；折叠屏半开时，上半视频、下半步骤。

## 2. 站点地图

```
今天（home）
├── 今晚吃什么 → 菜谱详情
├── 最近做过 → 菜谱详情
├── 快速收录 → 收录页
└── 搜索 → 搜索结果

菜谱（recipes）
├── 列表 / 搜索 / 筛选
└── 菜谱详情（recipe/{id}）
    ├── 食材（份量缩放、加入采购）
    ├── 步骤（跳转视频时间点）
    ├── 原文（来源快照、原链接）
    ├── 记录（烹饪历史、我的版本）
    ├── 开始做（cook/{id}）
    └── 编辑（edit/{id}）

采购（shopping）
├── 当前清单
├── 已购
└── 清空 / 导出为文本

我的（settings）
├── 存储空间
├── 导出备份 / 从备份恢复
├── 平台登录（login/{platform}）
├── 清除登录信息
├── 主题 / 仅 Wi-Fi 下载
└── 关于与隐私说明

收录（capture）
├── 粘贴框 / 剪贴板建议
├── 解析进度
├── 需要登录 → login/{platform}
└── 草稿收件箱（解析失败、待补全）
```

## 3. 导航规则

- **收录是一级动作**：手机底部导航中央的橙色悬浮按钮；平板放在 Rail 顶部与首页工具栏。从任何页面 1 次点击可达。
- **详情是「返回」而不是「切换 Tab」**：从首页/菜谱进入详情，返回回到来源页；从通知/分享进入，返回首页。
- **烹饪模式是全屏沉浸**：隐藏导航；退出需明确按钮或二次确认返回，防止油手误触。
- **搜索是全局的**：首页顶部与菜谱页共用；搜索结果可切「菜谱 / 食材 / 作者」。
- **草案不进入主列表**：未完成解析的进入「收录」页的草稿区，不污染菜谱库。

## 4. 页面清单

| 页面 | 目的 | 关键元素 | 空状态 | 错误状态 |
|---|---|---|---|---|
| 今天 | 决定今晚吃什么 | 大标题、今晚吃什么 3 张卡、最近做过横向列表、收录入口 | 引导收录第一条 | 数据库读取失败 → 重试 |
| 菜谱 | 浏览与查找 | 搜索、筛选 chips、网格/列表、排序 | 无菜谱 → 收录 CTA | 搜索无结果 → 清空条件 |
| 详情 | 看食材与步骤 | 封面、来源条、份量、食材、步骤、开始做 | 无食材 → 「补全食材」 | 媒体丢失 → 占位 + 重新下载 |
| 烹饪 | 照着做 | 步骤大字、进度、计时、上/下、退出 | 无步骤 → 显示原文 | 视频不可用 → 仅步骤 |
| 收录 | 把链接变菜谱 | 粘贴框、解析按钮、进度、草稿列表 | 无草稿 → 使用提示 | 需登录 / 风控 / 失败 → 对应动作 |
| 登录 | 保存平台 Cookie | WebView、说明、完成按钮 | — | 加载失败 → 重试/用系统浏览器 |
| 采购 | 买菜 | 分组清单、勾选、添加、清除已购 | 空清单 → 从菜谱添加 | 清单为空 → 空状态 |
| 我的 | 设置与数据 | 存储、备份、登录、主题、关于 | — | 导出失败 → 原因 |
| 编辑 | 修正菜谱 | 标题、份量、食材行、步骤行、来源链接 | — | 校验失败 → 行内提示 |

## 5. 首页逻辑（今晚吃什么）

候选池按优先级：

1. 收藏且 7 天没做过；
2. 收录超过 7 天从未做过（越久越靠前）；
3. 最近做过但评分 ≥4 的（「再做一次」）。

取 3 条，按「有封面优先、有食材优先」排序；同一天内不重复。若候选池为空，显示收录引导，而不是空白。

首页下方「最近做过」按 `lastCookedAt` 倒序取 6 条，横向滚动；没有记录时不显示该区块。

## 6. 全局状态

| 状态 | 呈现 |
|---|---|
| 离线 | 顶部细条「离线：已保存的内容仍可查看」；收录按钮禁用并说明 |
| 解析中 | 卡片骨架 + 进度文案；可取消 |
| 需登录 | 卡片 + 「去登录」；说明只保存在本机 |
| 风控 | 熔断提示 + 「手动保存后导入」 |
| 原链接失效 | 来源条显示「原链接可能失效」，但快照内容仍可读 |
| 待补全 | 菜谱卡片右上角橙色圆点；详情顶部提示条 |
| 媒体丢失 | 图片占位 + 「重新下载」 |

## 7. 深链接与快捷方式

- `weiji://open?url=...` → 收录页并自动解析。
- 桌面快捷方式：`paste` → 收录页聚焦粘贴框。
- 分享 Intent：`text/plain`、`image/*`、`video/*`、`SEND_MULTIPLE` → 收录页。
- 通知（下载完成/计时结束）→ 对应菜谱或烹饪页。

## 8. 搜索

MVP 搜索字段：菜名、食材名、作者、正文。排序：收藏优先，其次最近更新。
实现：SQL `LIKE` + 索引；数据量超过 2000 条再评估 FTS4。中文不做分词，按子串匹配。
