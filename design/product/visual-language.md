# 视觉语言与设计系统

> 方向：**Apple 风格的克制与秩序**——大标题、分组列表、克制的色彩、内容优先、动效服务于理解。
> 不是照搬 iOS 控件，而是借用它的信息层级与节奏，落在 Material 3 + Compose 上。

## 1. 品牌性格

**是**：克制、可信、有温度。
**不是**：花哨、拥挤、卡通风。

判断标准：任何一个界面，去掉装饰后是否仍然清楚？如果靠插画和渐变才成立，就是错的。

## 2. 色彩

### 2.1 浅色

| Token | 值 | 用途 |
|---|---|---|
| `background` | `#F2F2F7` | 页面底色（iOS systemGroupedBackground） |
| `surface` | `#FFFFFF` | 卡片、列表行、弹层 |
| `surfaceElevated` | `#FFFFFF` | 浮层、Sheet |
| `label` | `#000000` | 主文字 |
| `secondaryLabel` | `#6C6C70` | 次要文字、说明 |
| `tertiaryLabel` | `#8E8E93` | 占位、时间戳 |
| `separator` | `#C6C6C8` | 分隔线（1px hairline） |
| `tint` | `#FF9500` | 品牌主色（systemOrange）：收录、进度、强调 |
| `destructive` | `#FF3B30` | 删除、错误 |
| `success` | `#34C759` | 完成、已购 |
| `link` | `#007AFF` | 原链接、可点文字 |

### 2.2 深色

| Token | 值 |
|---|---|
| `background` | `#000000` |
| `surface` | `#1C1C1E` |
| `surfaceElevated` | `#2C2C2E` |
| `label` | `#FFFFFF` |
| `secondaryLabel` | `#EBEBF5`（99%） |
| `tertiaryLabel` | `#EBEBF5`（60%） |
| `separator` | `#38383A` |
| `tint` | `#FF9F0A` |
| `destructive` | `#FF453A` |
| `success` | `#30D158` |
| `link` | `#0A84FF` |

### 2.3 对比度

- 主文字/背景 ≥ 15:1（浅色黑字白底；深色白字黑底）。
- 次要文字/背景 ≥ 4.5:1（`#6C6C70` on `#FFFFFF` ≈ 5.1:1）。
- 橙色 `#FF9500` 配白字仅 2.5:1，**不用于小字**；橙色只做图标、进度、描边，橙色按钮用黑字（`#000` on `#FF9500` ≈ 8.9:1）。
- 烹饪模式：纯黑底 + 纯白字 + 橙色进度，对比度 > 17:1。

## 3. 字体

系统字体（Android 上为 Roboto + Noto Sans CJK），不内置字体，保证首屏与包体。

| 角色 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| Large Title | 34sp | 40sp | Bold | 页面大标题（今天、菜谱） |
| Title 1 | 28sp | 34sp | Bold | 详情标题 |
| Title 2 | 22sp | 28sp | Semibold | 区块标题 |
| Headline | 17sp | 22sp | Semibold | 列表主文字、按钮 |
| Body | 17sp | 26sp | Regular | 正文、步骤 |
| Subhead | 15sp | 22sp | Regular | 说明、食材行 |
| Footnote | 13sp | 18sp | Regular | 来源、时间 |
| Caption | 11sp | 14sp | Medium | 角标、标签 |
| Cook Step | 26sp | 38sp | Medium | 烹饪模式步骤 |
| Cook Step (tablet) | 30sp | 44sp | Medium | 平板远距离 |

支持系统字体缩放；`sp` 已随系统缩放。烹饪模式在字体缩放 >1.3 时自动降到 24sp，避免溢出。

## 4. 间距与形状

- 4pt 网格：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 页面左右边距：Compact 16，Medium 24，Expanded 32。
- 卡片内边距：16；列表行垂直 12。
- 圆角：小控件 10，卡片 14，大卡片/Sheet 20-28。
- 阴影：几乎不用；用 1px `separator` 描边与 `surface` 色差分层。
- 触控目标：常规 ≥48dp；烹饪模式 ≥64dp；图标按钮 44dp。

## 5. 组件

### 5.1 大标题页头
- 左对齐，34sp Bold，向下滚动时收缩为 17sp 导航标题（折叠动画 180ms）。
- 右侧最多 2 个图标按钮。

### 5.2 分组列表（Inset Grouped）
- 卡片圆角 14，行高 ≥52dp；行间 1px hairline，左边距 16。
- 行内：图标 24 + 主文字 17 + 右侧值/箭头 15 灰。
- 危险操作单独分组，红字。

### 5.3 菜谱卡
三种密度：
- **Hero（首页建议）**：16:9 封面，标题 20，来源角标，底部份量/时间。
- **Grid（菜谱页）**：1:1 封面，标题 17，两行截断，来源小字。
- **Row（最近做过/搜索结果）**：64×64 圆角封面 + 标题 + 元信息。

### 5.4 来源署名条（合规必需）
位于详情标题下、食材上方：
`抖音 · @西关焖烧男 · 原链接 ↗`
13sp，灰色；点击原链接走系统浏览器。不可隐藏、不可编辑为空。

### 5.5 步骤卡
- 序号圆点 28dp，橙色；文字 17sp，行高 26。
- 有图时图在上、文字在下，圆角 14。
- 有视频时间戳时显示 `00:42` 胶囊，点击跳转。

### 5.6 份量控件
- 胶囊分段：`1 2 3 4+`；选中橙色描边。
- 右侧显示「按 2 人份」；变化时食材数字 200ms 数字滚动。

### 5.7 分段控件（Segmented）
食材 / 步骤 / 原文 / 记录；高度 32，圆角 9，选中白底+阴影（深色为 `#636366`）。

### 5.8 搜索框
- 胶囊，高 36，底色 `#E5E5EA`（深色 `#1C1C1E`），左侧放大镜，占位「搜菜名、食材、作者」。

### 5.9 空状态
- 一个简单的线性插画（碗/蒸汽），标题 22，说明 15，主按钮橙色。
- 不使用夸张卡通。

### 5.10 动效
- 标准时长 220ms，spring(damping 0.9, stiffness 380)。
- 按压：scale 0.97 + 透明度 0.9。
- 页面切换：淡入+轻微上移 8dp；返回反向。
- 烹饪模式：只用 120ms 淡入淡出，不做位移与缩放，避免分心。
- 尊重系统「减少动态效果」。

## 6. 烹饪模式（独立视觉）

- 强制深色：`#000000` 背景，`#FFFFFF` 文字，`#FF9500` 进度。
- 顶部：退出 ×（44dp）+ 菜名 15sp 灰 + 进度 `3/8`。
- 中部：步骤文字 26-30sp，最多 6 行，超出可滚动。
- 底部：上一步/下一步两个 64dp 高按钮；中间计时器。
- 食材抽屉：从底部上拉，显示本步相关食材；不遮挡步骤。
- 屏幕常亮；音量键翻步；返回键二次确认。

## 7. 平板与折叠屏

- **不是放大手机**：同一屏显示更多信息，而不是把字变大。
- 菜谱页：3 列网格（≥840dp），2 列（600-840dp）。
- 详情页：左栏封面+食材，右栏步骤；宽度上限 720dp 的阅读栏。
- 烹饪模式：左 40% 视频/图片，右 60% 步骤；折叠屏半开时上下分屏。
- 导航：`NavigationRail` 宽 80dp，图标+文字；选中项橙色胶囊底。

## 9. 检查清单

- [ ] 每个页面只有一个主行动（橙色）
- [ ] 大标题 + 分组列表的节奏一致
- [ ] 没有纯装饰性渐变/阴影
- [ ] 所有可点元素 ≥48dp
- [ ] 深色模式下分隔线与文字对比度达标
- [ ] 平板不是手机拉伸
- [ ] 烹饪模式可在 1m 外读清
