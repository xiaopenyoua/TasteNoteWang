# 页面与交互规格

> 每个页面写四件事：结构、动作、状态、适配。数值来自设计系统，不在这里重复。

## 1. 今天（Home）

**结构**
- 大标题「今天」+ 日期/问候；右侧搜索、设置。
- 区块 1「今晚吃什么」：横向 3 张 Hero 卡（16:9 封面、标题 2 行、来源+份量）。
- 区块 2「最近做过」：横向 6 个 Row 卡（64 封面 + 标题）。
- 悬浮收录按钮（Compact）/ Rail 顶部按钮（Expanded）。

**动作**
- 点卡片 → 详情。
- 长按卡片 → 快捷菜单：开始做 / 加入采购 / 收藏。
- 点区块标题「全部」→ 菜谱页。
- 下拉刷新不做（本地数据实时 Flow）。

**状态**
- 空库：插画 + 「把第一条教程收进来」+ 两个按钮（粘贴链接 / 手动创建）。
- 离线：顶部细条；已缓存内容可看。
- 数据读取失败：整页错误 + 重试。

**适配**
- Medium：建议卡 2 列，最近做过 1 行 6 个。
- Expanded：左栏建议（2 列），右栏最近做过 + 统计（本周做过 N 次）。

## 2. 菜谱（Recipes）

**结构**
- 大标题「菜谱」+ 搜索框 + 筛选 chips（全部 / 收藏 / 没做过 / 快手 / 有视频）。
- Compact：单列 Row 卡或 2 列 Grid（可切换）。
- Medium：2 列；Expanded：3 列。
- 排序菜单：最近更新 / 最近做过 / 收藏优先 / 标题。

**动作**
- 点卡片 → 详情；长按 → 收藏 / 删除（二次确认，删除同时删媒体）。
- 搜索：输入 200ms 防抖；清空按钮。
- 筛选与搜索可叠加；无结果时显示「清除条件」。

**状态**
- 空：收录 CTA。
- 搜索中：轻量加载条（不遮挡列表）。
- 删除中：行内进度，可撤销（5 秒 Snackbar）。

## 3. 菜谱详情（Recipe/{id}）

**结构（Compact）**
1. 顶部封面 16:9（无封面用来源色块 + 菜名首字）。
2. 标题 28；副标题（作者/时间）。
3. 来源署名条（平台 · 作者 · 原链接）。
4. 元信息胶囊：份量、时长、难度、平台。
5. 分段控件：食材 / 步骤 / 原文 / 记录。
6. 底部固定操作条：开始做（主）、收藏、更多。

**食材**
- 份量胶囊 1-8；右侧「按 N 人份」。
- 分组（主料/辅料/酱汁）标题 + 行；数量右对齐；「适量」灰字。
- 每行左侧可勾选（备菜模式），勾选不改变数据。
- 底部「全部加入采购清单」。

**步骤**
- 步骤卡编号、文字、可选图片、可选时间戳胶囊。
- 点击时间戳 → 打开视频播放器并 seek；无视频时提示「原视频未下载」。
- 底部「开始做」。

**原文**
- 来源正文全文，保留换行与话题标签。
- 顶部提示：自动解析可能有误，可切到编辑修正。
- 原链接按钮（外部浏览器）。

**记录**
- 烹饪历史列表（日期、评分、份量、备注、照片）。
- 「我的版本」最新一条置顶；点开可查看/复制到编辑。
- 空状态：「还没做过，今晚试试？」

**动作**
- 收藏切换；编辑；删除；分享（导出单条 Markdown/图片，P1）。
- 返回：回到来源页。

**状态**
- 解析不完整：顶部橙色提示条「有 3 项待补全」→ 编辑。
- 媒体缺失：封面/步骤图占位 + 「重新下载」。
- 原链接可能失效：署名条附灰色说明。

**适配**
- Expanded：左栏封面+食材（可滚动），右栏步骤；来源条横跨。
- Medium：上下结构，食材/步骤切换。

## 4. 烹饪模式（Cook/{id}）

**进入**：详情「开始做」，或首页长按「开始做」。
**结构**
- 顶部：退出 ×、菜名、`3/8` 进度。
- 中部：步骤文字（26-30sp），必要时可滚；有图/视频时上方显示。
- 底部：上一步 / 下一步（64dp），中间计时按钮。
- 食材抽屉：上拉显示本步食材；关闭后回到步骤。
- 计时器：可创建多个，显示在底部；到点震动 + 通知。

**交互**
- 左右滑 = 上/下步；音量键 = 上/下步（可关）。
- 点步骤文字 → 朗读（P1）。
- 返回键 → 二次确认「退出烹饪？」。
- 屏幕常亮（默认开，可关）。
- 熄屏/切后台：保留当前步；回来恢复。

**结束**
- 最后一步显示「做完了」→ 10 秒记录 Sheet：
  - 评分（1-5 星，可跳过）
  - 份量（默认当前）
  - 一句改动（预填上次的改动）
  - 拍照（可选）
  - 保存 → 写 CookLog + 更新 lastCookedAt。

**状态**
- 无步骤：显示原文并提示「去补充步骤」。
- 视频不可用：只显示步骤，不阻塞。
- 计时到点：全屏顶部横幅 + 震动；点击停止。

**适配**
- Expanded：左 40% 视频/封面，右 60% 步骤；计时器在右栏底部。
- 折叠屏半开：上半播放，下半步骤。

## 5. 收录（Capture）

**结构**
- 顶部：标题「收录」+ 关闭。
- 大粘贴框（多行），自动读取剪贴板（前台，带「粘贴」按钮时更明确）。
- 识别到的平台胶囊 + 链接预览。
- 主按钮「解析」，次按钮「手动创建」。
- 下方「草稿」列表：解析中/失败/待补全，带状态与重试。

**流程**
1. 进入页面：若剪贴板有链接，显示「检测到抖音链接，是否解析？」。
2. 点解析 → 进度：解析中 → 下载中（n/m）→ 完成。
3. 完成 → 自动跳详情（可设置「留在收录页继续」）。
4. 需要登录 → 弹层「去登录」→ 登录页 → 返回自动重试。
5. 失败 → 卡片显示原因 + 「重试」「只保留链接」。

**状态文案**
- 解析中：「正在读取抖音页面…」
- 下载中：「正在下载视频 12.4 MB / 28.1 MB」
- 风控：「平台暂时限制了访问，已保留链接和文字。可以稍后重试，或在平台内保存后导入。」
- 无媒体：「已保存标题和文字，媒体可稍后补。」

**适配**
- Expanded：左粘贴/进度，右草稿列表。
- 键盘弹出时按钮跟随，不被遮挡。

## 6. 平台登录（Login/{platform}）

**结构**
- 标题「登录抖音」+ 关闭。
- 说明卡：「只用于读取你主动提交的链接；Cookie 加密保存在本机，不会上传。」
- WebView（全宽），底部「我已登录」按钮。
- 右上「清除登录信息」。

**交互**
- 用户在 WebView 内自行登录；应用不读取账号密码。
- 点「我已登录」→ 读取 CookieManager 的 Cookie → 加密保存 → 返回并重试。
- 若 WebView 无法登录 → 提供「用系统浏览器打开」但不采集 Cookie（降级）。

## 7. 采购（Shopping）

**结构**
- 大标题「采购」+ 添加按钮。
- 清单名 + 进度（已购/总数）。
- 分组：肉禽水产 / 蔬菜 / 蛋奶 / 调料 / 其他。
- 行：勾选框、名称、数量、来源菜谱（灰字）。
- 底部：清除已购、清空清单、复制为文本。

**交互**
- 勾选 → 划线 + 下沉到「已购」。
- 左滑删除；撤销 5 秒。
- 从菜谱加入时按名称+单位去重，数量相加（P1）。

## 8. 我的（Settings）

分组列表：
1. **数据**：存储空间（DB/图片/视频/可用）、导出备份、从备份恢复。
2. **收录**：仅 Wi-Fi 下载、自动下载媒体、平台登录状态（三个开关/入口）、清除全部登录信息。
3. **体验**：主题（跟随系统/浅色/深色）、烹饪常亮、音量键翻步。
4. **关于**：版本、隐私说明、开源许可、数据目录。

危险操作（清除登录、清空数据）红字 + 二次确认。

## 9. 编辑（Edit/{id}）

- 标题、份量、时长、来源链接。
- 食材编辑：可增删行；名称/数量/单位三段；「适量」开关。
- 步骤编辑：可增删、拖拽排序；每步可设定时秒数。
- 保存：校验标题非空；食材名称非空；步骤可为空但提示。
- 未保存返回：二次确认。

## 10. 无障碍与性能

- 所有图标按钮有 `contentDescription`。
- 步骤卡与食材行支持 TalkBack 顺序阅读。
- 颜色不作为唯一信息载体（收藏同时有图标）。
- 列表使用稳定 `key`；图片使用 Coil 固定尺寸，避免跳动。
- 详情进入时先显示 DB 数据，再异步加载图片；不做全屏 loading。
